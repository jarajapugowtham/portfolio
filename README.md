# Jarajapu Gowtham — WOW Spider-Inspired Portfolio

A cinematic, Spider-Man-inspired React/Vite portfolio for Jarajapu Gowtham.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Important: profile photo

The chat-uploaded profile photo is intentionally not embedded as a fake remote URL. Replace the hero placeholder in `src/main.jsx` with your image file (for example `/public/gowtham.jpg`) when deploying.

## Resume button

Replace the temporary Google Drive placeholder in `src/main.jsx` with your actual hosted resume URL before deployment.
