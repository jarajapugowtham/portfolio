# My Portfolio

A simple portfolio website built with React and Vite.

## Features
- Responsive design
- Portfolio sections like Hero, About, Projects, Skills, and Contact
- Fast build with Vite
- Easy deployment on Vercel

## Tech Stack
- React
- Vite
- JavaScript
- CSS
